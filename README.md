# Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание

Проект представляет собой адаптивную версию многостраничного HTML/CSS-сайта интернет-магазина (ShopProject), разработанную без использования сторонних фреймворков (Bootstrap и др.) на основе чистого семантического HTML5, современных возможностей CSS (Custom Properties, Flexbox, CSS Grid, clamp, responsive images) и нативного JavaScript.

## Практическая работа №12

Выполнено:
- создан отдельный репозиторий `kr3-responsive-shop`;
- перенесена основа проекта из контрольной работы №1;
- подключён отдельный файл адаптивных стилей `css/responsive.css` на всех страницах после `style.css`;
- проверено наличие корректного метатега `viewport`;
- применён подход **Mobile First**: базовые стили рассчитаны на компактные экраны, расширения строятся на медиазапросах с `min-width`;
- адаптированы шапка и навигация: вертикальное меню на мобильных, адаптивная строка на планшетах и десктопах (`min-width: 768px` / `1024px`);
- настроена sticky-навигация: статичное позиционирование на мобильных устройствах, закрепление на планшетах и десктопах с защитой от перекрытия контента;
- адаптирован hero-блок с использованием гибкой типографики (`clamp()`) и двухколоночной сетки на десктопе;
- адаптирована сетка карточек товаров: 1 колонка (мобильные) → 2 колонки (`640px`) → 3 колонки (`1024px`) → 4 колонки (`1280px`);
- адаптирована страница каталога и боковой фильтр: фильтр размещён над товарами на мобильных (`order: -1`) и трансформируется в sticky-сайдбар на десктопах;
- добавлены **Responsive Images**:
  - нативный элемент `<picture>` с медиазапросами для разных экранов в hero-блоке (`hero-mobile.jpg`, `hero-tablet.jpg`, `hero-desktop.jpg`);
  - атрибуты `srcset` и `sizes` для изображений карточек товаров (`product-1-480.jpg`, `product-1-640.jpg`, `product-1-960.jpg`), с указанием `width`, `height` и `loading="lazy"`;
  - поддержка пропорций `aspect-ratio: 4 / 3` и `object-fit: cover`;
- адаптирована форма заявки (как модальное окно `<dialog>`, так и страница `order.html`): одноколоночный вид на смартфонах с сенсорно-комфортными полями (`min-height: 44px`) и двухколоночная сетка на планшетах/десктопах;
- адаптированы таблицы (характеристики товара и таблица сравнения) через обёртку `.table-wrapper` с плавной горизонтальной прокруткой (`overflow-x: auto`);
- адаптировано модальное окно `dialog` (`width: min(100% - 32px, 560px)`, ограничение по высоте `calc(100vh - 32px)` и скролл длинного содержимого);
- адаптирована фиксированная кнопка «Наверх» с удобной областью клика (44×44px+);
- выполнена проверка в DevTools на всех ключевых разрешениях;
- обновлён `sitemap.xml` и оформлены изменения через ветку `feature/responsive-layout`.

## Проверенные ширины (DevTools)

- **360px** — компактный мобильный экран;
- **430px** — современный смартфон повышенного разрешения;
- **768px** — планшет в портретной ориентации;
- **1024px** — небольшой desktop / ноутбук / планшет в альбомной ориентации;
- **1440px** — широкий монитор.

## БЭМ-структура и ключевые компоненты

- `site-header` — шапка сайта (с модификатором адаптивности в `responsive.css`);
- `site-nav` — адаптивная навигация (flex-direction: column → row);
- `hero` — промо-блок с адаптивным заголовком и `<picture>`;
- `products-grid` — сетка каталога на CSS Grid;
- `product-card` — адаптивная карточка товара;
- `catalog-layout`, `catalog-filters`, `catalog-products` — адаптивная раскладка каталога;
- `order-dialog`, `order-form` — форма заказа со свойствами touch-friendly;
- `table-wrapper`, `product-table` — адаптивные таблицы с горизонтальным скроллом;
- `reviews__list`, `review-card` — адаптивная сетка отзывов;
- `site-footer` — подвал сайта.
